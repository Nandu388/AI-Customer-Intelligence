# 🤖 AI-Driven Customer Intelligence Platform
# Demo link : https://ai-customer-intelligence-hmvg.onrender.com

An AI-powered customer analytics platform built using Streamlit, Machine Learning, and Data Visualization.

This system helps businesses analyze customer behavior, predict purchases, identify churn risk, and generate personalized recommendations using AI-driven insights.

---

# 📌 Problem Statement

Businesses struggle to understand complex customer behavior patterns from vast datasets, leading to suboptimal marketing strategies and poor customer experience.

Traditional analytics provide only static reports, lacking dynamic insights and predictive capabilities.

This project provides an AI-driven platform that uses:

- Machine Learning
- Predictive Analytics
- Customer Segmentation
- Recommendation Systems
- Interactive Dashboards

to improve customer engagement and business growth.

# 📦 Installation

## Step 1 — Clone Project

```bash
git clone <repository-url>
```

---

## Step 2 — Open Project

```bash
cd AI_Customer_Intelligence_Platform
```

---

## Step 3 — Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 📊 Generate Dataset

Run:

```bash
python generate_dataset.py
```

This generates:

* 500 customer records
* Customer demographics
* Purchase history
* Product categories
* Spending behavior

---

# 🤖 Train Machine Learning Model

Run:

```bash
python train_models.py
```

This creates:

```text
models/churn_model.pkl
```

---

# ▶️ Run Application

Run:

```bash
streamlit run app.py
```
